# Training Loss Record Status

No standalone training-loss file was generated by the completed two-epoch run.
The original `train.py` printed running batch loss and final epoch loss to the
terminal only; it did not write a CSV, JSON, TensorBoard event, or image.

For future runs, redirect the terminal output to a text file, for example:

```powershell
py -m face_recognition.train --data-root ./faces_emore --output-dir runs/resnet50_arcface 2>&1 | Tee-Object training_loss.log
```

The existing checkpoint does not contain a recoverable per-batch or per-epoch
loss history, so this module intentionally does not fabricate loss values.
